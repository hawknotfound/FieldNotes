# Career Path: Startup Builder

Starting your own company or joining an early-stage startup.

## What this looks like

Building a startup in India is more accessible than ever. Lower costs, better funding environment, and a growing customer base make it viable for young founders.

## Typical trajectory

1. Identify a problem (talk to people, observe)
2. Validate the problem (will anyone pay for a solution?)
3. Build an MVP (minimum viable product)
4. Get first users
5. Raise funding or become profitable
6. Scale

## Paths to startup building

| Path | Description | Risk |
|---|---|---|
| Founder | Start your own company | High |
| Early employee (startup #1-20) | Join before Series A | Medium |
| Venture building | Work at a startup studio | Medium |
| Campus founder | Start while in college | High but low cost |

## Skills needed

| Skill | Priority |
|---|---|
| Problem identification | Essential |
| Sales / communication | Essential |
| Basic tech (or find a co-founder) | Important |
| Financial literacy | Important |
| Resilience | Essential |

## India context

- College founders are common — many startups began in IITs, IIITs
- Incubators: AIC, T-Hub, CIIE, NSRCEL
- Startup India registration offers tax benefits
- DPIIT recognition makes fundraising easier
- Bangalore is the startup capital

## Where to start

- Join a college E-Cell
- Participate in startup competitions (Hult Prize, Eureka)
- Read about Indian startup ecosystem (YourStory, Inc42)
- Solve a problem you experience yourself
- Talk to 20 potential users before building anything
- Find a co-founder with complementary skills
