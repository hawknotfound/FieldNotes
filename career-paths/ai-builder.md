# Career Path: AI Builder

Building AI-powered products and applications.

## What this looks like

You do not need to be a research scientist to work in AI. Most AI jobs in India are about **applying AI**, not inventing it: building products that use LLMs, computer vision, or recommendation systems.

## Typical trajectory

1. Learn Python + basic ML concepts
2. Build projects that use AI APIs (OpenAI, Gemini, Claude)
3. Learn RAG, prompt engineering, evaluation
4. Build a portfolio of deployed AI projects
5. Internship at a company building AI products
6. Full-time as ML engineer / AI engineer

## Skills needed

| Skill | Priority |
|---|---|
| Python | Essential |
| API integration | Essential |
| Prompt engineering | Important |
| RAG | Important |
| Basic ML theory | Good to have |
| Docker / deployment | Good to have |

## India context

- Bangalore, Hyderabad, Pune, Delhi-NCR have most AI jobs
- AI engineers with 1-3 years experience: ₹8-20 LPA
- WITCH companies (TCS, Infosys, Wipro) hire AI engineers at scale
- AI startup scene is active in Bangalore
