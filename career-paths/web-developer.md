# Career Path: Web Developer

Building websites, web apps, and digital products.

## What this looks like

Web development is the most accessible tech career in India. It has the most entry-level jobs and the clearest learning path.

## Typical trajectory

1. Learn HTML, CSS, JavaScript
2. Learn a framework (React, Next.js, or Vue)
3. Learn backend basics (Node.js, Express)
4. Build 3-5 full projects
5. Freelance or intern
6. Full-time frontend/backend/full-stack developer

## Specializations

| Role | What you build |
|---|---|
| Frontend | What users see (UI, design) |
| Backend | Servers, APIs, databases |
| Full-stack | Both of the above |
| DevOps | Deployment, scaling, infrastructure |

## Skills needed

| Skill | Priority |
|---|---|
| HTML/CSS/JS | Essential |
| React or Next.js | Important |
| Git/GitHub | Essential |
| Basic backend | Important |
| Database basics | Important |

## India context

- Most IT jobs in India are web development
- Fresher salaries: ₹3-8 LPA (varies by city and company)
- Remote work is common
- Freelancing is viable (₹10,000-50,000/month for students)

## Where to start

- [The Odin Project](https://theodinproject.com)
- [freeCodeCamp](https://freecodecamp.org)
- Build a portfolio website, a blog, a todo app
- Participate in hackathons
- Contribute to open source
