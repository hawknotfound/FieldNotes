# Career Path: Commerce + Tech

Bridging commerce/business skills with technology — a powerful combination in India.

## What this looks like

You do not have to be an engineer to work in tech. Companies need people who understand both business and technology. This is where commerce students with tech skills have an edge.

## Common roles

| Role | What you do | Typical companies |
|---|---|---|
| Product Manager | Define what to build | All tech companies |
| Business Analyst | Analyze data for decisions | Consulting, tech |
| Growth Marketer | Drive user acquisition | Startups, D2C brands |
| Tech Sales | Sell technical products | SaaS companies |
| Program Manager | Coordinate product launches | Amazon, Flipkart |
| Finance + fintech | Financial products | Fintech startups |

## Skills needed

| Skill | Priority |
|---|---|
| Communication | Essential |
| Excel / Sheets | Essential |
| SQL | Important |
| Basic analytics | Important |
| Presentation skills | Essential |
| Basic Python (optional) | Differentiator |

## How commerce and tech connect in India

- **Fintech:** Razorpay, PhonePe, CRED, Zerodha — need commerce knowledge
- **E-commerce:** Flipkart, Amazon, Meesho — business operations
- **Edtech:** Unacademy, Byju's, upGrad — marketing and growth
- **SaaS:** Freshworks, Zoho — sales and customer success

## Where to start

- Learn SQL (can do in 2 weeks)
- Learn Excel/Google Sheets deeply
- Learn basic data analysis and visualization
- Participate in business case competitions
- Take a few CS courses (CS50 is free)
- Build a side project that blends commerce and tech

## India context

- Commerce students from DU, Mumbai University, and other top colleges get into product roles
- Companies value business acumen + analytical skills more than coding ability for many roles
- Startups prefer generalists who can do multiple things
- Freelancing in data analysis is accessible
