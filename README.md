# FieldNotes

A structured, research-driven knowledge base for students in India who want to go beyond the classroom.

Practical notes on hackathons, competitions, innovation, exams, cities, networking, travel, skills, opportunities, and more — all curated for the Indian student context.

New here? Pick your path:

- **"I have an event coming up, what should I expect?"** → [`field-notes/`](field-notes/index.md) (before, during, after)

## Who this is for

- Students in India exploring hackathons, competitions, and real-world exposure
- Anyone preparing for their first event and unsure where to start
- Students who want to travel, network, and build skills outside their curriculum
- Commerce, science, and humanities students looking for relevant opportunities
- Self-learners who prefer structured, practical information over motivational noise

## How to use this

- **New to everything?** Use the quick start paths above.
- **Browsing?** Each folder has an `index.md` that explains the topic and links to relevant files.
- **Need step-by-step plans?** [`roadmaps/`](roadmaps/index.md) has actionable checklists.
- **Want real experiences?** [`field-notes/`](field-notes/index.md) shares grounded observations from actual events.
- **Sharing with friends?** Use the [`hinglish/`](hinglish/index.md) section for natural Hinglish content.
- **Sharing with parents?** Use the [`parents/`](parents/index.md) section (Hindi).
- **Planning an event trip?** Start with [`travel/`](travel/index.md) and [`cities/`](cities/index.md).
- **Discovering opportunities?** Follow the system in [`opportunities/how-to-discover.md`](opportunities/how-to-discover.md).
- **Evaluating an opportunity?** Start with [`decision-frameworks/red-flags-and-green-flags.md`](decision-frameworks/red-flags-and-green-flags.md), then use the full scoring system in [`decision-frameworks/opportunity-evaluation-framework.md`](decision-frameworks/opportunity-evaluation-framework.md).
- **Not sure if an opportunity is worth it?** Use the 5-question pre-filter in [`decision-frameworks/is-this-worth-applying-for.md`](decision-frameworks/is-this-worth-applying-for.md).
- **Deciding whether to travel for an event?** Use [`decision-frameworks/travel-worthiness-checklist.md`](decision-frameworks/travel-worthiness-checklist.md).
- **Need to discuss an event with parents?** Prepare with [`decision-frameworks/parent-discussion-checklist.md`](decision-frameworks/parent-discussion-checklist.md).
- **About to register for an event?** Run through [`decision-frameworks/event-readiness-checklist.md`](decision-frameworks/event-readiness-checklist.md).
- **Finding live and recurring opportunities?** Check [`hackathons/`](hackathons/index.md) and [`opportunities/`](opportunities/index.md).
- **Reading stories for perspective?** See [`stories/`](stories/index.md).
- **Maintainer notes?** See [`meta/`](meta/index.md).

## Why this exists

Indian students have access to a growing number of opportunities — hackathons, competitions, innovation challenges, and more — but finding them, understanding them, and acting on them requires effort that is not always well-supported by school or college curricula.

This repository collects what I have learned and researched so that others can benefit from structured, practical information without having to start from scratch.

It is a public resource. Contributions, corrections, and additions are welcome.

## Content principles

- **English** section: clean, practical, public-repo ready
- **Hinglish** section: natural, conversational, shareable with friends
- **Hindi** section (parents/): respectful, simple, for family audiences
- Research-based, not speculative
- Practical and actionable, not motivational
- Beginner-friendly but not simplistic
- India-focused with specific context
- Clearly marked when information about dates or availability is uncertain
