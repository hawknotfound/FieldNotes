# Latest Priority — Class 11–12 Commerce × AI

This folder is built for one specific person: a **Class 11 or 12 commerce student** who is **new to coding**, genuinely interested in **AI and research**, and wants to **do something real** — not just study theory.

Every opportunity here is filtered through:
- Can a **beginner** actually attempt this?
- Is it **India-friendly** (time zone, cost, location)?
- Does it value **writing, research, business thinking** — not just code?
- Will it look **credible on a resume or college application**?

## How the opportunities are structured

Every entry uses this format:

| Field | What it means |
|---|---|
| **What** | Name of the opportunity |
| **Organizer** | Who runs it |
| **Website** | Where to register or read more |
| **Deadline** | When to apply. "TBD" = not announced yet. |
| **Eligibility** | Who can participate (class, stream, age) |
| **Format** | Online / offline / hybrid |
| **Cost** | Free or paid |
| **Solo?** | Can you do it alone (yes / team / both) |
| **Difficulty** | Beginner / Medium / Hard |
| **Coding needed?** | Yes / No / Optional |
| **Prize / Outcome** | What you get if you win or complete |
| **Why it fits** | Why this works for a commerce + AI student |
| **Watch out** | Risks, hidden costs, time commitment |
| **Last verified** | When this info was checked |

## What NOT in this folder

- Opportunities that require engineering enrolment
- Programs that cost money without clear value
- Events already passed without confirmed 2027 dates
- Generic "motivational" career advice — only executable entries
