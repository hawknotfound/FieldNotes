# Student Fellowships & Scholarships

Most fellowships are for college or PhD students. But there are a few gems for school students — and many more you can plan for.

---

## Available Now (School Level)

### 1. National Scholarship Portal (NSP) Schemes

| Field | Detail |
|---|---|
| **Website** | [scholarships.gov.in](https://scholarships.gov.in) |
| **Status** | Open for AY 2026-27 from June 1, 2026 |
| **Eligibility** | Varies by scheme (class, income, category, merit) |
| **Format** | Online |
| **Cost** | Free |
| **Key schemes** | Pre-Matric, Post-Matric, Merit-coume-Means, various ministry-specific |
| **Why apply** | Central government portal. Single application for multiple schemes. |

### 2. School-Specific Scholarships

Most schools and state boards offer their own scholarships for Class 11-12 students. Check with your school's scholarship coordinator. Common types:
- Merit-based (top 1-5% in board exams)
- Category-based (SC/ST/OBC/Economically Weaker)
- Subject toppers (accounts, business studies, economics)
- Sports quota

### 3. Buddy4Study Platform

| Field | Detail |
|---|---|
| **Website** | [buddy4study.com](https://www.buddy4study.com) |
| **Status** | Year-round (new scholarships added regularly) |
| **Cost** | Free |
| **Why use it** | India's largest scholarship aggregator. Filters by class, stream, state, category. |

## Plan For (College Level)

### 4. Google Summer of Code (GSoC)

| Field | Detail |
|---|---|
| **Organizer** | Google |
| **Website** | [summerofcode.withgoogle.com](https://summerofcode.withgoogle.com) |
| **Deadline** | Applications ~March 2027 |
| **Eligibility** | 18+, open source contributors |
| **Format** | Remote, 12 weeks |
| **Stipend** | ~₹1.5-2L for Indian participants (previous years) |
| **Why plan now** | Start contributing to open source in Class 11-12. By college, you'll have 2+ years of contributions and a strong GSoC application. |

### 5. Amity University Summer Research Fellowship

| Field | Detail |

## Scholarship Search Strategy

1. **Now (Class 11-12)** : Apply through NSP + check Buddy4Study monthly
2. **School level**: Ask your school's scholarship coordinator
3. **State level**: Check your state board's scholarship portal
4. **College prep**: Start open source contributions NOW for GSoC
5. **Category**: If applicable, check ministry-specific schemes (minority, OBC, SC/ST, EWS)
