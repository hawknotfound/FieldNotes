## How to hack a hackathon as a non-coder

You don't need to code to contribute meaningfully:

1. **Product strategy** — Define the problem, target users, business model
2. **Research** — Market size, competitor analysis, feasibility
3. **Pitch + presentation** — Most winning teams win on presentation, not code quality
4. **UI/UX** — Wireframes, user flows, mockups (using Figma — no code needed)
5. **Documentation** — Clear README, project report, demo script
6. **Business model** — Monetization, unit economics, go-to-market

Find 1-2 coders, bring the above skills, and you're valuable.
