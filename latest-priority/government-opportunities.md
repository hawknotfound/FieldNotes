# Government-Backed Opportunities

Government programs carry weight. They're credible, usually free, and many are open to school-level commerce students.

---

## 1. Smart India Hackathon (SIH) Junior

| Field | Detail |
|---|---|
| **Organizer** | Ministry of Education, AICTE |
| **Website** | [junior.sih.gov.in](https://junior.sih.gov.in) |
| **Deadline** | Varies |
| **Eligibility** | Classes 6–12 |
| **Format** | Idea submission |
| **Cost** | Free |
| **Coding?** | No |
| **Prize** | National recognition, government certification |
| **Why it fits** | Government's own school innovation challenge. No coding required. |

## 2. Smart India Hackathon (SIH) — Main Edition

| Field | Detail |
|---|---|
| **Organizer** | Ministry of Education, AICTE |
| **Website** | [sih.gov.in](https://www.sih.gov.in) |
| **Deadline** | Jul-Aug registration (annual) |
| **Eligibility** | College students (UG/PG/PhD) |
| **Format** | Online qualifier + offline finale |
| **Cost** | Free |
| **Coding?** | Yes (but non-coding roles exist in a 6-member team) |
| **Prize** | ₹1,00,000 per problem statement |
| **Why it fits** | If you're heading to college, SIH is the biggest stage. Commerce students can handle business, presentation, documentation. |
| **Watch out** | Requires college SPOC registration. Team size of 6 is large. |

## Pro tip

Government programs often have **irregular schedules** and **website changes**. Always:
- Verify dates on the official website before applying
- Register early (portals crash near deadlines)
- Check eligibility twice — many have category/fee/region restrictions
