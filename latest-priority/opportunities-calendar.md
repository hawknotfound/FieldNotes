## What to do if you're overwhelmed

1. **Pick 3 from the entire year** — one olympiad, one competition, one learning program
2. **Don't do everything** — depth over breadth
3. **The calendar is a planning tool, not a checklist** — skip months where you need to focus on board exams
4. **Calendar priority order**: Board exams → Olympiad/competition → Hackathon/event → Everything else
