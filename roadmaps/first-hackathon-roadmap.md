# Roadmap: First Hackathon

A step-by-step action plan for your first hackathon.

---

## Phase 1: Foundation (2-3 weeks before)

- [ ] Pick a language/framework you are comfortable with (Python or JavaScript recommended)
- [ ] Build one small project from scratch (todo app, calculator, landing page)
- [ ] Set up Git and GitHub
- [ ] Find 2-3 teammates (or join a hackathon that forms teams)

## Phase 2: Choose the Right Event (1-2 weeks before)

- [ ] Pick an online hackathon (easier for first time)
- [ ] Look for beginner-friendly tags or mentorship mentions
- [ ] Register and join the event Discord/Slack
- [ ] Read the rules, schedule, and judging criteria

## Phase 3: Preparation (3-5 days before)

- [ ] Team call to discuss ideas (30 min)
- [ ] Decide tech stack (what you already know > what is trendy)
- [ ] Install and test all tools (IDE, frameworks, APIs)
- [ ] Prepare templates (auth, basic CRUD, styling framework)
- [ ] Set up a shared GitHub repo with your team

## Phase 4: Hackathon Day

**First 2 hours:**
- [ ] Finalize idea (simple > complex)
- [ ] Assign roles clearly
- [ ] Set up project structure
- [ ] Start coding

**Middle hours:**
- [ ] Focus on core functionality first
- [ ] Ask mentors for help early
- [ ] Take short breaks
- [ ] Keep the team communicating

**Last 4 hours:**
- [ ] Freeze features — no new ideas now
- [ ] Fix critical bugs
- [ ] Prepare presentation slides
- [ ] Record a demo video (backup plan)

**Last hour:**
- [ ] Submit on time
- [ ] Upload code to GitHub
- [ ] Submit presentation

## Phase 5: After the Hackathon

- [ ] Get some sleep
- [ ] Review what went well and what did not
- [ ] Push final code with a good README
- [ ] Post on LinkedIn about your experience
- [ ] Connect with teammates and people you met
- [ ] Decide on the next hackathon

---

## Quick checklist

```
[ ] Basic skills ready
[ ] Team formed
[ ] Event registered
[ ] Tools installed
[ ] Idea decided
[ ] Roles assigned
[ ] Core feature working
[ ] Presentation ready
[ ] Submitted on time
```

---

## Time allocation (24-hour hackathon)

| Activity | Hours |
|---|---|
| Planning & idea finalization | 2 |
| Core development | 10 |
| Feature completion | 4 |
| Bug fixing & polish | 4 |
| Presentation prep | 2 |
| Buffer | 2 |
| **Total** | **24** |
