# Roadmap: Build Your GitHub Presence

A plan to turn your GitHub profile into a professional asset.

---

## Phase 1: Foundation (Week 1)

- [ ] Create a GitHub account (if you do not have one)
- [ ] Set up a profile README (github.com/yourusername/yourusername)
- [ ] Clean profile photo
- [ ] Add a bio: what you build, what you are learning
- [ ] Pin your best projects

**Profile README template:**
```markdown
### Hi there 👋

I'm [Name], a [year] student at [college] in India.

🔭 I build [web apps / AI tools / mobile apps]
🌱 Currently learning [tech]
⚡ Fun fact: [something about you]

[![Top Langs](https://github-readme-stats.vercel.app/api/top-langs/?username=yourusername)]
```

---

## Phase 2: First Projects (Week 2-3)

- [ ] Create repositories for your projects
- [ ] Write good READMEs (what, why, how, stack, screenshots)
- [ ] Add a .gitignore file
- [ ] Add a license (MIT is fine for most student projects)
- [ ] Make sure the code runs (test before pushing)

**Good README structure:**
```
# Project Name
## What it does
## Tech stack
## How to run
## Screenshots
## What I learned
## Links (live demo, blog post)
```

---

## Phase 3: Consistency (Week 4-8)

- [ ] Commit at least 3-4 times per week
- [ ] Work on at least one meaningful project
- [ ] Write meaningful commit messages (not "update" or "fix")
- [ ] Keep a contribution streak going

---

## Phase 4: Open Source Contribution (Week 6-10)

- [ ] Find beginner-friendly repos (label: "good first issue")
- [ ] Read CONTRIBUTING.md of the project
- [ ] Start with documentation fixes
- [ ] Move to small code contributions
- [ ] Engage in issues and pull requests

**Where to find beginner issues:**
- [Good First Issues](https://goodfirstissues.com)
- [Up For Grabs](https://up-for-grabs.net)
- [Hacktoberfest](https://hacktoberfest.com) (October)
- [GSSoC](https://gssoc.girlscript.tech) (Indian open source program)

---

## Phase 5: Portfolio

- [ ] Create a portfolio repo that links to all your projects
- [ ] Cross-link: GitHub ← → LinkedIn ← → portfolio website
- [ ] Write a short bio that connects your projects to your interests
- [ ] Keep pinned repos updated

---

## What recruiters look for

| Signal | What it shows |
|---|---|
| Active commits (3+/week) | Consistency |
| Clean README | Communication |
| Meaningful projects | Practical skills |
| Open source contributions | Collaboration |
| Code quality | Engineering discipline |

---

## Avoid these

- Empty repositories with just a README
- One commit with 500 files on the last day of a hackathon
- Copied projects from tutorials without changes
- No README or description
- "Delete this later" as a project name
- No commits for 6+ months

---

## Monthly maintenance

- [ ] Review and archive old repos
- [ ] Update profile README
- [ ] Update pinned repos
- [ ] Write at least one new README or update existing ones
- [ ] Check contribution graph — is it green?
