# Roadmap: Student Networking

A step-by-step plan to build your professional network.

---

## Phase 1: Foundation (Week 1-2)

### Online profiles
- [ ] Optimize LinkedIn profile (photo, headline, about, experience)
- [ ] Create a GitHub profile (if tech) — clean README on profile
- [ ] Set up Twitter/X (optional, but useful for tech networking)
- [ ] Create a clean email signature

### Content
- [ ] Post about one thing you learned this week
- [ ] Comment thoughtfully on 3 posts from your field
- [ ] Write one short post about a project you built

## Phase 2: Find Communities (Week 2-3)

- [ ] Find 2-3 online communities (Discord, Telegram, WhatsApp)
- [ ] Introduce yourself in the #introductions channel
- [ ] Answer one question someone else asked
- [ ] Attend one online meetup or workshop

## Phase 3: Attend Events (Week 3-6)

### Online events
- [ ] Register for an online hackathon/workshop
- [ ] Join the event chat
- [ ] Message 2-3 people during the event ("Hi, I liked your project...")
- [ ] Connect on LinkedIn after the event

### Offline events (if available)
- [ ] Find a local meetup (GDG, FOSS United, college fest)
- [ ] Prepare a 30-second introduction about yourself
- [ ] Talk to at least 3 new people
- [ ] Exchange LinkedIn or contact info

## Phase 4: Follow Up (ongoing)

- [ ] Within 24 hours: send LinkedIn request with a message
- [ ] Within 1 week: share something useful with new connections
- [ ] Monthly: check in with 5 people in your network

## Phase 5: Give Back

- [ ] Offer to help someone (review their project, give feedback)
- [ ] Share opportunities you find with your network
- [ ] Write about what you have learned
- [ ] Mentor someone newer than you

---

## Monthly networking habits

| Frequency | Action |
|---|---|
| Daily | Comment on 1-2 posts in your field |
| Weekly | Post something (learning, project, opinion) |
| Weekly | DM 1 person with a genuine compliment/question |
| Monthly | Attend one event (online or offline) |
| Monthly | Review your connections and follow up |
| Quarterly | Write a longer post or article |

---

## Follow-up message template

```
Hi [Name],

I met you at [Event] where you [specific thing — "were judging the AI track" / "presented your project on..."].

I really liked [specific detail]. I am working on [your thing] and would love to stay connected.

Thanks,
[Your Name]
```
