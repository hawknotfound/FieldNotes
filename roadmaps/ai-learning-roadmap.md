# Roadmap: AI Learning

A step-by-step plan to go from zero to building AI-powered projects.

---

## Phase 1: Prerequisites (2-4 weeks)

**Goal:** Enough Python to build simple programs.

- [ ] Variables, data types, conditionals
- [ ] Loops, functions, lists, dictionaries
- [ ] File I/O (reading/writing files)
- [ ] Installing packages with pip
- [ ] Using Jupyter notebooks or Google Colab

**Resource:** [Python for Everybody](https://freecodecamp.org) — chapters 1-10

---

## Phase 2: AI Tool Proficiency (1-2 weeks)

**Goal:** Use AI tools effectively in your daily workflow.

- [ ] Learn to write clear prompts (context + task + format)
- [ ] Use ChatGPT/Gemini/Claude for learning and coding help
- [ ] Use Perplexity for research
- [ ] Use Copilot or Cursor for code generation

**Resource:** [ai/prompts-and-workflows.md](../ai/prompts-and-workflows.md)

---

## Phase 3: Core Concepts (3-4 weeks)

**Goal:** Understand key AI concepts without getting lost in math.

- [ ] What are LLMs and how they work (high level)
- [ ] What is an API and how to call one
- [ ] Prompt engineering patterns
- [ ] Embeddings and vector search (concept)
- [ ] RAG (Retrieval Augmented Generation)

**Resource:** [DeepLearning.AI short courses](https://deeplearning.ai)

---

## Phase 4: Build Projects (4-6 weeks)

**Goal:** Ship 3 AI projects for your portfolio.

### Project 1: Simple Chatbot
- Use OpenAI/Gemini API
- Add system prompt + conversation history
- Deploy on Streamlit

### Project 2: RAG App
- Load a PDF or set of documents
- Chunk and embed them
- Answer questions based on your documents

### Project 3: AI Tool
- Whatever you find useful (study assistant, code reviewer, content summarizer)
- Add features you actually need

---

## Phase 5: Level Up (ongoing)

- [ ] Learn basic ML with scikit-learn
- [ ] Participate in a Kaggle competition
- [ ] Fine-tune a small model (LLaMA, Mistral)
- [ ] Learn deployment (Docker, cloud)
- [ ] Build an AI agent (function calling, tool use)

---
