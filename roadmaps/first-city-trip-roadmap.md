# Roadmap: First Solo/Group City Trip for an Event

A step-by-step action plan for traveling to a hackathon or competition in another city.

---

## Phase 1: Confirm the Event (3-4 weeks before)

- [ ] Register for the event and save the confirmation
- [ ] Read all event communications (schedule, venue, what to bring)
- [ ] Check if event provides food/accommodation
- [ ] Confirm team members who are attending

## Phase 2: Plan Travel (2-3 weeks before)

### Route
- [ ] Decide train vs bus vs flight
- [ ] Book tickets (train: IRCTC, bus: RedBus/IntrCity, flight: student fare)
- [ ] Download offline map of the city
- [ ] Note the route from station/airport to venue

### Stay
- [ ] If event provides stay: confirm with organizers
- [ ] If booking yourself: hostel > OYO > hotel (in order of cost)
- [ ] Share address with parents

### Budget
- [ ] Calculate: travel + stay + food + misc
- [ ] Add 20% buffer
- [ ] Carry ₹500-1000 emergency cash

## Phase 3: Pack (1-2 days before)

- [ ] Laptop + charger (with extension cord)
- [ ] Phone charger + power bank
- [ ] College ID + Aadhaar (physical copy)
- [ ] Water bottle
- [ ] Earphones / headphones
- [ ] Small notebook + pen
- [ ] Hoodie/jacket (venues are cold)
- [ ] Basic toiletries
- [ ] Any medicines you may need

## Phase 4: Travel Day

- [ ] Leave early (2x buffer for traffic)
- [ ] Share live location with parents
- [ ] Reach station/airport 30 min early
- [ ] On arrival: go directly to venue or stay
- [ ] Check in, drop bags, register at event

## Phase 5: During the Event

- [ ] Follow hackathon/event schedule
- [ ] Eat properly (most events provide meals)
- [ ] Sleep if possible (multi-day events)
- [ ] Network with other participants
- [ ] Keep your belongings safe

## Phase 6: Return

- [ ] Book return travel in advance
- [ ] Leave with enough buffer for return journey
- [ ] Reach home and confirm to parents
- [ ] Rest

---

## Checklist for first trip

```
[ ] Event confirmed and registered
[ ] Travel booked (with confirmation)
[ ] Stay confirmed
[ ] Budget prepared
[ ] Parents informed with full details
[ ] Live location sharing set up
[ ] Emergency contacts saved
[ ] Packed (see list above)
[ ] Return travel booked
[ ] Emergency cash carried
```
