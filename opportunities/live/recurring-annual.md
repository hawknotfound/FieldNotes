# Recurring Annual Opportunities

Events that happen every year with predictable timing. Use this to plan your year. **Dates are based on past editions and are not confirmed until officially announced.**

---

## Smart India Hackathon (SIH) — Main Edition

| Detail | Info |
|---|---|
| **Organizer** | Ministry of Education, AICTE |
| **Website** | [sih.gov.in](https://www.sih.gov.in) |
| **Typical Months** | August–December |
| **Registration** | Through college SPOC, usually opens July–August |
| **Eligibility** | All UG/PG/PhD students in recognized Indian institutions |
| **Team Size** | 6 members + 1-2 mentors |
| **Prize** | ₹1,00,000 per problem statement |
| **Format** | Software + Hardware editions |

The biggest student hackathon globally by participation. Problem statements from government ministries. Winning is a career-defining achievement. Most competitive but worth attempting.

## Flipkart GRiD

| Detail | Info |
|---|---|
| **Organizer** | Flipkart |
| **Website** | [flipkartcareers.com/students](https://www.flipkartcareers.com/students) |
| **Typical Months** | July–November |
| **Registration** | Usually June–August on Unstop |
| **Eligibility** | Engineering students (B.Tech/B.E./M.Tech) |
| **Prize** | ₹5L+ prizes + SDE-1 offers (up to ₹32 LPA) |

India's largest engineering campus challenge. Multiple tracks (software, security, robotics). Direct path to Flipkart SDE roles. Extremely competitive (5L+ registrations in GRiD 6.0).

## Goldman Sachs India Hackathon

| Detail | Info |
|---|---|
| **Organizer** | Goldman Sachs |
| **Website** | [goldmansachs.com/careers](https://www.goldmansachs.com/careers/students/programs-and-internships/india/hackathon) |

## Google Summer of Code (GSoC)

| Detail | Info |
|---|---|
| **Organizer** | Google |
| **Website** | [summerofcode.withgoogle.com](https://summerofcode.withgoogle.com) |
| **Typical Months** | Contributor applications ~March-April. Coding period June-September. |
| **Eligibility** | Open source contributors aged 18+ |
| **Format** | Remote, 12-week coding project |
| **Stipend** | Paid (Indian participants: ~₹1.5-2L previous years) |

World's most prestigious open source program. Extremely competitive but life-changing. Start contributing to open source 6-12 months before the application cycle.

## India Innovates

| Detail | Info |
|---|---|
| **Organizer** | Municipal Corporation of Delhi (2026 edition) |
| **Website** | [indiainnovates.org](https://indiainnovates.org) |
| **Typical Months** | January–March |
| **Eligibility** | All students across India (team of 3-6) |

## National Ideathon (by ComSIA)

## Recurring by month (general pattern)

This is a rough guide based on when these events typically happen. Individual dates vary.

| Month | What typically opens / happens |
|---|---|
| **January** | India Innovates registration, some college-fest hackathons |
| **February** | GSoC organization applications, Ideathon finals, SIH Junior (sometimes) |
| **March** | GSoC contributor applications open, India Innovates finale, National Ideathon finale |
| **April** | Goldman Sachs hackathon applications open |
| **May** | Goldman Sachs hackathon, some online hackathons |
| **June** | HSBC / Flipkart GRiD registration, MLH season events |
| **July** | Flipkart GRiD goes live, HSBC hackathon, SIH preparations begin |
| **August** | SIH registration opens via college SPOC, more college fests |
| **September** | SIH problem statements release, School Youth Ideathon registration |
| **October** | SIH submissions, Hacktoberfest |
| **November** | SIH grand finale, year-end college fests |
| **December** | Next year's ideathon registrations begin |
