## Content guidelines (for contributors)

- English only in main folders
- Hinglish content should have a separate, clearly labeled folder
- Every folder should have an index.md that explains the topic
- Files should be useful at a glance — structured, scannable, practical
- Avoid motivational language, vague advice, and filler
- If information about dates or availability is uncertain, state it clearly
- Source links when relevant and verifiable

## How to contribute

If you want to add content:
1. Follow the folder structure and naming conventions
2. Write in clear, practical English
3. Research before writing — avoid speculation
4. Add links to sources when making factual claims
5. Create a PR or open an issue explaining what you are adding and why

## Editorial principles

- Practical > theoretical
- Specific > general
- Verified > speculative
- Beginner-friendly but not condescending
- India-focused with relevant context
