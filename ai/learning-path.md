# AI Learning Path for Students

A practical, phased path to learn AI skills — from zero to building useful things.

---

## Phase 0: Prerequisites (2-4 weeks)

Before touching AI specifically, have basic programming skills:

- Python basics: variables, loops, functions, lists, dictionaries
- Basic data handling: reading CSV, simple pandas operations
- Installing packages with pip
- Using Jupyter notebooks or Google Colab

**Resources:**
- [Python for Everybody](https://freecodecamp.org) (freeCodeCamp)
- [CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python)
- [Google's Python Class](https://developers.google.com/edu/python)

---

## Phase 1: Using AI Tools (1-2 weeks)

Start by using existing AI tools effectively:

- Learn to prompt ChatGPT/Claude/Gemini well
- Use Copilot or Cursor for coding
- Use Perplexity for research
- Use AI for writing, summarizing, brainstorming

**Goal:** Become comfortable with AI as a tool in your workflow.

---

## Phase 2: AI Concepts (3-4 weeks)

Understand the fundamentals without getting lost in math:

| Topic | What to learn | Why |
|---|---|---|
| What is ML | Supervised vs unsupervised | Core concept |
| LLMs | How text generation works | Foundation of modern AI |
| Embeddings | Converting text to numbers | RAG, search |
| RAG | Adding your data to LLMs | Practical applications |
| Prompt engineering | Crafting effective prompts | Everyday skill |

**Resources:**
- [DeepLearning.AI Short Courses](https://deeplearning.ai) (many are free)
- [Hugging Face NLP Course](https://huggingface.co/learn/nlp-course)
- [3Blue1Brown Neural Networks](https://youtube.com/playlist?list=PLZHQObOWTQDNU6R1_67000Dx_ZCJB-3pi)

---

## Phase 3: Building with AI (4-6 weeks)

Build projects that use AI. Do not train models — use APIs.

**Project ideas:**

| Project | Skills Learned |
|---|---|
| Chatbot for a specific topic | RAG, prompt engineering |
| AI-powered study assistant | APIs, file processing |
| Code review tool | LLM evaluation, prompt patterns |
| Content summarizer | API integration, text processing |
| AI flashcards generator | Structured output, batch processing |

**Tech stack:** Python + OpenAI/Gemini API + Streamlit/Gradio for UI

---

## Phase 4: AI + Data (4-6 weeks)

Learn to work with data alongside AI:

- Data cleaning with pandas
- Basic visualization (matplotlib, seaborn)
- Feature engineering basics
- Training simple models (scikit-learn)
- Model evaluation

**Resources:**
- [Kaggle Learn](https://kaggle.com/learn)
- [StatQuest YouTube](https://youtube.com/@statquest)
- [Fast.ai Practical Deep Learning](https://course.fast.ai)

---

## Phase 5: Advanced Topics (ongoing)

- Fine-tuning open-source models (LLaMA, Mistral)
- Building AI agents
- Deploying ML models
- MLOps basics
- AI safety and ethics

---

## Time commitment

| Phase | Duration | Daily time | Result |
|---|---|---|---|
| 0 | 2-4 weeks | 30 min | Python basics |
| 1 | 1-2 weeks | 15 min | Effective AI user |
| 2 | 3-4 weeks | 30 min | Understand concepts |
| 3 | 4-6 weeks | 1 hour | Build AI projects |
| 4 | 4-6 weeks | 1 hour | Data + AI skills |
| 5 | Ongoing | Variable | Deep expertise |

---

## Key principle

Build first, theory later. You do not need to understand transformers to build a useful chatbot. You do not need to know calculus to use an AI API. Learn what you need when you need it.
