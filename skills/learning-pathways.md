# Learning Pathways

Structured learning paths for common student goals.

---

## Pathway 1: Hackathon-ready developer

**Goal:** Build and ship a project in 24-48 hours

| Phase | Time | What to learn | Resources |
|---|---|---|---|
| 1 | 2 weeks | HTML, CSS, JavaScript basics | freeCodeCamp, The Odin Project |
| 2 | 2 weeks | React or Vue basics | Official docs, YouTube tutorials |
| 3 | 1 week | Git & GitHub | GitHub Guides |
| 4 | 1 week | API basics (REST, fetch) | MDN, Postman Student |
| 5 | 2 weeks | Build a full-stack project | MERN stack tutorial |
| 6 | Ongoing | Participate in online hackathons | Devfolio, Devpost |

---

## Pathway 2: Competitive programmer

**Goal:** Reach 1400+ rating on Codeforces / 4-star on CodeChef

| Phase | Time | Focus | Resources |
|---|---|---|---|
| 1 | 1 month | Arrays, strings, basic math | Codeforces Div 4, AtCoder ABC |
| 2 | 2 months | Sorting, searching, greedy | CSES Problem Set |
| 3 | 2 months | DP, graphs, trees | CP-Algorithms, USACO Guide |
| 4 | 3 months | Advanced topics (flows, strings, etc.) | CF blogs, coaching platforms |
| Practice | Ongoing | 2-3 contests per week | Codeforces, AtCoder, CodeChef |

---

## Pathway 3: Startup founder / Innovator

**Goal:** Validate and pitch an idea

| Phase | Time | Focus | Resources |
|---|---|---|---|
| 1 | 2 weeks | Problem identification | Customer interviews, observation |
| 2 | 2 weeks | Solution design | Lean Canvas, Figma wireframes |
| 3 | 4 weeks | Build MVP | Low-code or no-code tools, or dev partner |
| 4 | 2 weeks | Pitch deck creation | Pitch deck examples (PitchHub) |
| 5 | Ongoing | Participate in competitions | Hult Prize, Eureka, Unstop |

---

## Pathway 4: Design-focused builder

**Goal:** Create polished, user-friendly interfaces

| Phase | Time | Focus | Resources |
|---|---|---|---|
| 1 | 2 weeks | Design principles | Figma 101 course, Design+Code |
| 2 | 3 weeks | UI design practice | Redesign existing apps in Figma |
| 3 | 2 weeks | Basic frontend dev | HTML/CSS, Tailwind CSS |
| 4 | 2 weeks | Design systems | Learn component libraries |
| 5 | Ongoing | Real projects | Contribute to open source designs |

---

## Pathway 5: Event networker

**Goal:** Build professional connections and opportunities

| Phase | Time | Focus | Resources |
|---|---|---|---|
| 1 | 1 week | Optimize LinkedIn profile | Profile guides, peer review |
| 2 | 2 weeks | Start posting | Share learnings, projects |
| 3 | 2 weeks | Join communities | Discord, Telegram, WhatsApp groups |
| 4 | Ongoing | Attend events | Start local, then national |
| 5 | Ongoing | Follow up systematically | Notion/CRM for contacts |
