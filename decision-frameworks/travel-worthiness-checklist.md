# Travel Worthiness Checklist

Should you travel to another city for this event? Use this before booking anything.

## The 7 questions

### 1. Distance and travel time

- Under 100 km / Under 3 hours → Travel is easy. Low cost.
- 100-300 km / 3-8 hours → Moderate. Overnight train works.
- 300-1000 km / 8-16 hours → Significant. Need overnight travel.
- 1000+ km / 16+ hours → Major trip. Need flight or 2-day travel.

### 2. Total cost

Calculate: travel (round trip) + accommodation + food + local transport + contingency.

| Band | Amount |
|---|---|
| Under ₹1,000 | Low. Easy to justify. |
| ₹1,000-₹3,000 | Moderate. Should be offset by learning value. |
| ₹3,000-₹6,000 | Significant. Only if the event is high quality. |
| ₹6,000+ | High. Must be a top-tier opportunity with clear ROI. |

### 3. Learning value compared to local alternatives

- Can I get similar learning from an event in my own city? Yes → Travel may not be worth it.
- Is the learning at this event unique and unavailable locally? Yes → Strong reason to travel.

### 4. Networking value of THIS specific location

- Does this city have a stronger tech/industry scene than my city?
- Will I meet people I cannot meet at home?
- Will the participant quality be higher because of location?

Examples: Bangalore has higher networking value for tech events than a Tier-2 city. Delhi has higher networking value for policy events.

### 5. Uniqueness

- Is this the only edition of this event this year? → High uniqueness.
- Does this event happen in my city regularly? → Lower uniqueness.
- Is this specific edition special? (National finals, anniversary edition, special guests)

### 6. Future relevance

- Will attending this event open doors to future opportunities? (Selection for national finals, mentorship connections, direct internship paths)
- Will this event look good on a resume for your target career?
- Will you get a certificate, recommendation letter, or portfolio piece?

### 7. Personal readiness

- Do you have the budget without financial strain?
- Do you have permission from parents/college?
- Can you handle the physical demands (travel fatigue, sleep loss)?
- Do you have a backup plan if something goes wrong?

## Decision table

| High learning value? | High networking value? | Unique? | Cost manageable? | Decision |
|---|---|---|---|---|
| Yes | Yes | Yes | Yes | **Travel. Worth it.** |
| Yes | Yes | No | Yes | **Travel. Good opportunity.** |
| Yes | No | Yes | Yes | **Travel. Learning alone justifies it.** |
| No | Yes | Yes | Yes | **Travel. Only if networking is your priority.** |
| Yes | No | No | No | **Skip.** Similar events available locally. |
| No | No | No | Any | **Skip.** Not worth the effort. |

## Quick scoring version

Score 1-3 for each:

| Factor | 1 (Weak) | 2 (Medium) | 3 (Strong) |
|---|---|---|---|
| Learning value | Same as local events | Better than local | Unique, cannot get elsewhere |
| Networking value | Minimal | Some useful contacts | High-value, relevant network |
| Uniqueness | Many similar events | Fewer alternatives | Rare chance |
| Cost burden | High (₹6k+) | Moderate (₹2-6k) | Low (under ₹2k) |
| Future relevance | Low | Medium | Opens clear doors |

**Total out of 15:**
- 12-15 → Travel
- 8-11 → Travel if you have budget and time
- Below 8 → Skip

## Example: Traveling Delhi → Bangalore for a hackathon

| Factor | Assessment |
|---|---|
| Distance | ~2,200 km. Flight or 2-day train. |
| Total cost | ₹5,000-₹7,000 |
| Learning value | High. Bangalore hackathons have better mentors and industry involvement. |
| Networking value | Very high. Bangalore is India's tech hub. |
| Uniqueness | Depends on the specific hackathon. If it is a well-known one (Flipkart Grid, national finals), high uniqueness. |
| Future relevance | High. Connections made here can lead to internships and jobs. |
| **Verdict** | **Travel, if budget allows and the hackathon is well-regarded.** |

## Example: Traveling to a nearby city (100 km) for a college fest hackathon

| Factor | Assessment |
|---|---|
| Distance | 100 km. 2-3 hours by bus/train. |
| Total cost | Under ₹1,000 |
| Learning value | Similar to what is available locally |
| Networking value | Moderate. Different college crowd. |
| Uniqueness | Low. Many such fests. |
| Future relevance | Low-moderate |
| **Verdict** | **Go if you have free time and energy. Skip if you are busy. Not a high-priority trip.** |
