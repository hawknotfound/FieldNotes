# Is This Worth Applying For?

A 5-question pre-filter. Spend 2 minutes before spending 2 hours on an application.

## The 5 questions

### 1. Do I meet ALL eligibility criteria?

Check: class/year, age, marks/percentage, nationality, field of study, prior experience.

- Yes → Continue
- No → **Skip**. You will not be selected even if you apply well.
- Unsure → Check the FAQ or email the organizers. If they do not respond in 72 hours, treat it as a no.

### 2. Is the deadline far enough?

- At least 7 days away → Continue
- Less than 7 days → Proceed only if you have most materials ready. Rushed applications rarely succeed.
- Deadline is unclear or says "rolling admissions" → Set your own deadline 2 weeks out.

### 3. Can I commit the required time?

The event itself + travel + preparation + recovery.

Quick calculation:
- Preparation: 5-20 hours depending on type (hackathon, fellowship essay, competition prep)
- Event duration: 1-7 days
- Travel: 1-2 days round trip
- Recovery: 1 day after

If the total time conflicts with exams, family commitments, or health, **skip this cycle and catch the next one**. Most good events recur.

### 4. Does this genuinely interest me?

Be honest. Are you applying because:
- You care about the topic → **Yes** → Good signal
- It looks good on a resume → **Probably** → Acceptable reason but lowers your motivation
- Your friends are doing it → **Danger** → You will not put in real effort
- You have nothing better to do → **Skip** → Find something you actually want

### 5. Is the application process reasonable?

- Free to apply? → Good
- Requires essays, portfolio, or project? → Manageable if you have material
- Requires recommendation letters with <1 week notice? → Stressful but possible
- Requires payment? → **Red flag** (see red-flags-and-green-flags.md)

## Decision matrix

| Q1 (Eligible) | Q2 (Time) | Q3 (Commit) | Q4 (Interest) | Q5 (Reasonable) | Decision |
|---|---|---|---|---|---|
| Yes | Yes | Yes | Yes | Yes | **Apply. Strong candidate.** |
| Yes | Yes | Yes | Yes | No | Think carefully. Is the application burden worth it? |
| Yes | Yes | Yes | No | Yes | Apply only if it has high signal value for your career. |
| Yes | Yes | No | Yes | Yes | **Skip this cycle.** Catch the next one when you have time. |
| Yes | No | Yes | Yes | Yes | Apply only if you can complete materials in <48 hours. |
| No | Any | Any | Any | Any | **Skip.** |
| Any | Any | Any | Any | Any (fee) | **Skip** unless it is a verified government program. |
