# Coding Competitions

Competitive programming and coding competitions for Indian students.

---

## ICPC (International Collegiate Programming Contest)

- **Organizer:** ICPC Foundation, ACM
- **Format:** Team of 3, algorithmic problem-solving
- **Eligibility:** College students (undergrad/postgrad)
- **Region:** Asia West region includes India
- **Pathway:** College regionals → Asia West Finals → World Finals
- **Website:** [icpc.global](https://icpc.global)

ICPC is the most prestigious team programming competition. Indian teams regularly qualify for world finals from IITs, IIITs, NITs, and other universities.

**Preparation:**
- Practice on Codeforces, AtCoder
- Study algorithms and data structures (CLRS, CP-Algorithms)
- Solve ICPC regionals problem sets from previous years

---

## CodeChef

- **Organizer:** Unacademy (formerly CodeChef)
- **Format:** Individual, online
- **Key contests:** Starters (weekly), Cook-Off (monthly), Lunchtime (monthly)
- **Rating system:** Used widely for hiring in India
- **Website:** [codechef.com](https://codechef.com)

CodeChef is the largest competitive programming platform based in India. Many Indian companies use CodeChef ratings as a screening criterion.

---

## Codeforces

- **Organizer:** Independent (Mike Mirzayanov)
- **Format:** Individual, online
- **Key contests:** Div 1/2/3/4 rounds (multiple per month)
- **Rating system:** Global, widely respected
- **Website:** [codeforces.com](https://codeforces.com)

Codeforces is the most active competitive programming platform globally. Indian students make up a large portion of its user base.

---

## AtCoder

- **Organizer:** AtCoder Inc. (Japan)
- **Format:** Individual, online
- **Key contests:** ABC (weekly), ARC (monthly), AGC (quarterly)
- **Website:** [atcoder.jp](https://atcoder.jp)

AtCoder Beginner Contest (ABC) is excellent for students starting competitive programming. Problems are well-structured with clear difficulty progression.

## Meta Hacker Cup

Meta Hacker Cup replaced the old Facebook Hacker Cup. It is open globally.

- **Website:** [techgig.com/codegladiators](https://techgig.com/codegladiators)

## LeetCode Contests

- **Organizer:** LeetCode
- **Format:** Weekly (Saturday), Biweekly (Sunday)
- **Focus:** Interview preparation, DSA
- **Website:** [leetcode.com/contest](https://leetcode.com/contest)

LeetCode contests are particularly useful for students preparing for tech interviews.

## How to get started with competitive programming

1. Pick a language (C++ is most common, Python and Java also work)
2. Learn basic data structures and algorithms
3. Start with beginner-friendly contests (CodeChef Starters, AtCoder ABC)
4. Practice consistently — 1-2 problems daily
5. After solving, read editorial solutions to learn better approaches
6. Track your progress on platforms like Codeforces and CodeChef

## Why competitive programming matters

- Top tech companies use CP ratings for resume screening
- ICPC experience is highly valued in India for tech roles
- Builds strong algorithmic thinking
- Creates a measurable skill profile (Codeforces rating)
- Opens doors to global competitions and networking
